# Decisions

One file per design decision. A decision records its context, the options, the choice and the reasoning, so that later readers can see why the spec says what it does.

Status values: **Open** (not yet decided), **Accepted**, **Superseded by D-n**.

| ID | Decision | Status | Decide before |
| --- | --- | --- | --- |
| [D-1](D-1-weight-formula.md) | Weight formula: linear or squared in amount | Open | Draft NIP |
| [D-2](D-2-identity-commitment.md) | Identity commitment: key tweak or hash in script | Open | Signet |
| [D-3](D-3-event-kind.md) | Final event kind number | Open | Signet |
| [D-4](D-4-mainnet-cap.md) | Mainnet beta cap per bond | Open | Mainnet beta |
| [D-5](D-5-licence.md) | Licence | Open | First public push |
| [D-6](D-6-orangecheck.md) | Relationship to OrangeCheck | Open | Draft NIP |

To add one, copy an existing file, take the next number, and open a pull request. When a decision is accepted, update the spec documents it affects in the same pull request.
