# Changelog

Spec releases are tagged `spec-vMAJOR.MINOR.PATCH`.

- **MAJOR**: a change that alters addresses, scripts, event tags or verification results. It needs a new protocol version (`v` tag).
- **MINOR**: new optional tags, clarifications that tighten an ambiguous rule, new test vectors.
- **PATCH**: wording and typo fixes with no effect on behaviour.

## Unreleased

- Initial draft of protocol version 1, documents 00 to 07, taken from the 17 November 2026 technical specification.
