# D-4 · Mainnet beta cap

Status: Open · Affects: [06](../spec/06-networks.md)

## Context

Version 1 is hot-wallet only, and the fund-handling code is new. A cap per bond limits how much an unknown bug can cost. The cap is an implementation limit, not a verification rule: a verifier still counts a larger bond.

## Proposal

1,000,000 sats per bond during the mainnet beta.

## Decision

Not yet made.
